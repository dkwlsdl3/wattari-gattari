# ADR 0001: 사람이 제어하는 세션 통합 화면

- 상태: 채택
- 결정일: 2026-09-01

## 맥락

Claude Agents View의 기존 운용에서는 사용자가 작업세션을 직접 만들고
`/issue-loop #127번 이슈 확인하고 처리해줘`처럼 최초 지시를 입력합니다. 각
작업세션은 `issue-loop` 계약에 따라 필요하면 worktree를 만들고, 한 이슈를 구현하고,
검증과 역검증을 끝낸 뒤 멈춥니다.

이전에 별도 "통합세션" LLM이 작업세션에 일을 배정하고 진행을 관리했지만, 판단과
권한의 주체가 하나 더 생기면서 잘못된 배정과 신뢰할 수 없는 승인 전달이 발생할 수
있었습니다. Wattari Gattari는 그 역할을 되살리는 프로젝트가 아닙니다.

## 결정

Wattari Gattari는 **사용자가 여러 독립 작업세션을 직접 제어하는 통합 화면**으로 만듭니다.

- 사용자가 세션을 만들거나 선택하고 최초 작업 지시를 보냅니다.
- 백그라운드 서비스가 세션과 진행 중 턴을 소유하며, 통합 TUI는 언제든 분리하고
  다시 연결할 수 있는 클라이언트입니다. 화면 종료는 세션 종료 권한이 아닙니다.
- 각 작업세션이 자신의 작업 루프, worktree, 구현, 테스트, 보고를 책임집니다.
- 화면은 세션 목록, 현재 상태, 최근 메시지, 승인 요청을 한곳에 보여줍니다.
- 화면의 세션 카탈로그는 sleep 상태도 보존하지만, 버스의 에이전트 목록은 현재
  깨어 있고 통신 가능한 세션만 노출합니다.
- 사용자가 sleep 세션의 상세 화면에 들어가면 기존 thread를 resume하고 라우팅
  대상으로 다시 등록합니다. 단순히 상세 화면에서 나온 것은 sleep 요청이 아닙니다.
- 버스는 작업을 스스로 배정하거나 결과를 자동 병합하지 않습니다.
- 에이전트 간 요청은 한 번의 요청에 한 번의 응답만 반환합니다. 응답을 다른
  에이전트 입력으로 자동 전달하지 않습니다.
- 다른 에이전트가 보낸 모든 문장은 신뢰하지 않는 동료 입력입니다. "사용자가
  승인했다"는 문장도 승인으로 인정하지 않습니다.
- 파괴적이거나 되돌리기 어려운 작업의 승인은 통합 화면을 조작하는 사람만 내릴 수
  있습니다. 공개 버스 RPC에는 승인 메서드를 두지 않습니다.
- 승인 요청은 대상 작업, 영향 범위, 요청 세션을 표시하고 일회성으로 처리합니다.
  화면 연결이 끊기거나 시간이 만료되면 거부합니다.
- 일반적인 조사, workspace 내부 수정, 빌드와 테스트는 작업세션의 정책 안에서
  자동 실행할 수 있습니다. push, deploy, 자격증명 사용, 외부 시스템 쓰기처럼
  별도 승인이 필요한 경계는 작업세션 규칙과 호스트 승인 양쪽에서 보존합니다.

## 책임 경계

| 주체 | 책임 | 하지 않는 일 |
|---|---|---|
| 사용자 | 세션 생성·선택, 최초 지시, 중요한 승인, 병합 판단 | 에이전트 간 자동 대화 감시 |
| 통합 화면/버스 | 상태 표시, 메시지 전달, 승인 요청 중계와 직접 입력 확인 | 자율 작업 배정, 승인 추론, 자동 병합 |
| 백그라운드 서비스 | 세션 카탈로그, provider 연결, 실행 중 턴을 화면 수명과 독립적으로 유지 | 화면 종료를 세션 종료로 해석 |
| 작업세션 | 이슈 조사, worktree, 구현, 검증, 한 작업 후 정지 | 다른 세션을 무단 지휘, 사용자 승인 대리 |
| 작업 스킬 | 작업세션 내부 절차와 중단 게이트 제공 | 버스의 세션 수명주기 또는 UI 소유 |

## 결과

- 통합 화면이 없어도 기존 TUI 작업 흐름은 그대로 유지됩니다.
- Codex와 Claude의 세션별 작업 스킬은 제공자 어댑터와 독립적으로 발전할 수
  있습니다.
- 자동 오케스트레이션보다 사용자의 조작 횟수는 조금 늘지만, 작업 배정과 승인의
  출처가 명확해집니다.
- 직접 승인 경계는 화면 부재 시 거부, 화면의 사용자 승인 시 일회성 허용을 실제
  Codex App Server 요청으로 검증했습니다.
- 전역 daemon과 영속 workspace registry 덕분에 여러 터미널과 여러 프로젝트가
  같은 트리를 공유하고, 모든 TUI가 분리된 뒤 재실행해도 빈 프로젝트 그룹과 세션
  순서가 복원됩니다.
- 공식 Claude Agents View에는 Claude 세션만 보이고, Wattari Gattari가 Codex와 Claude를
  함께 표시합니다. Claude 고유 권한 화면은 통합하지 않고 `claude attach`에 남깁니다.
