# TUI v0 문서 상태

이 문서가 설명하던 커스텀 대화 화면은 2026-09-02에 폐기했습니다.

입력 composer, transcript 렌더링, 자체 슬래시 메뉴, 토큰 추정 상태선, 마우스 추적과
통합 승인 화면은 제공자 기본 TUI와 기능이 중복되고 유지보수 및 터미널 회귀 비용이
컸습니다. 현재 Waga 화면은 프로젝트·세션 개요와 수명주기 제어만 담당합니다.

현재 계약과 근거는 [ADR 0002](adr/0002-native-provider-tui-wrapper.md), 사용법은
[영문 README](../README.md)와 [한글 README](../README.ko.md)를 기준으로 합니다.
