# 로컬 라우터 루프 프로토콜

- 이슈 메타데이터는 모델 호출이 아니라 로컬 점수 계산에만 사용합니다.
- GitLab 조회는 이슈 번호가 있는 라우팅 요청에서 한 번 수행하고, 실패하면 입력
  프롬프트만으로 계속합니다.
- 외부 데이터는 작업 지시·승인·자동 실행으로 승격하지 않습니다.
- Waga 경계는 v1 응답의 모델·effort·tier·근거와 공개용 이슈 메타데이터만 받습니다.
  본문·코멘트 원문은 응답에서 제거하고 알 수 없는 root/issue 필드는 거부합니다.
  조회 전체 deadline은 12초로 제한합니다.
- 변경 전후 `npm run check`와 라우터 CLI의 JSON 결과를 확인합니다.
